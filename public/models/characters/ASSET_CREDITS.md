# Character model credits and licenses

The game loads only the selected player model. The original GLB files are kept local in `public/`; no model-generation service is required at runtime.

## CC0 models

- **Quaternius Adventurer** — `quaternius-adventurer.glb`, from Quaternius via [Poly Pizza](https://poly.pizza/m/5EGWBMpuXq). The listing identifies the asset as CC0. This attached model contains 24 animation clips, including idle, walk, run, interaction and wave actions.
- **Quaternius Animated Human** — `quaternius-animated-human.glb`, from [Poly Pizza](https://poly.pizza/m/c3Ibh9I3udk). The listing identifies it as CC0; the GLB contains eight animation clips, including idle, walk, run and jump.
- **Quaternius Animated Woman** — `quaternius-animated-woman.glb`, from [Poly Pizza](https://poly.pizza/m/nIItLV9nxS). The listing identifies it as CC0. See the GLB for its exact embedded clip list.
- **Kenney Adventurer** — `../kenney-adventurer.glb`, from the free [Kenney Animated Characters 3](https://kenney-assets.itch.io/animated-characters-3) pack. The original license is included at `../Kenney-CC0-License.txt`.

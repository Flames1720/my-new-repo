# Quick Run proposal

Player feedback: the 100-wave challenge is enjoyable but can feel exhausting. Keep it available and give players a shorter game with a definite finish. This document is a proposal; no game modes or rewards have been changed.

| Mode | Purpose | Finish |
| --- | --- | --- |
| Survival | Existing long challenge | 100 waves or defeat |
| Quick Run | Proposed short, complete session | 10 waves, ending with a boss |

Quick Run should reuse the controls, weapons and field cards players already know. Start with a manageable first wave, increase pressure over the run, and make wave 10 a clear finale. A boss at wave 5 could introduce that threat before the final fight. Tune enemy counts, spawn spacing and breaks together so mobile performance stays stable.

The session-length target is still open: about 5–8 minutes or about 10–15 minutes. Choose the target before deciding how fast waves arrive. Difficulty choices can later let players repeat the same short format with stronger threats; introduce them after the base mode feels good.

Keep XP comparable for time and difficulty across modes. Avoid a large flat completion bonus that makes repeating easy runs the fastest route to every card. Show kills, waves cleared, XP and victory/defeat clearly on the results screen. A win should feel rewarding even without a card purchase.

The lobby should offer a clear mode choice with wave count and estimated duration. The tutorial should explain controls once, then apply to either mode. Quick Run needs a distinct victory screen and a fast Play Again action.

Before release, measure completed runs, time to finish, the waves where players lose, and XP per minute. Tag run reports with the selected mode so performance and balance can be compared separately. Measure those outcomes explicitly; sampled performance windows alone cannot establish completion or abandonment.

This first proposal is a solo Quick Run. Multiplayer and competitive ranking would need their own design and server work.
